# 📘 Assignment: Functions and Lists

## 🎯 Objective

Learn how to write reusable functions and organize data with lists so students can build more flexible and maintainable Python programs.

## 📝 Tasks

### 🛠️ Define Reusable Functions

#### Description
Write functions that perform clear, single-purpose tasks using inputs and return values.

#### Requirements
Completed program should:

- Define a function called `greet(name)` that returns a personalized greeting
- Define a function called `add_numbers(a, b)` that returns the sum of two numbers
- Call each function with sample values and print the result
- Explain in comments how each function helps organize the program

### 🛠️ Work with Lists

#### Description
Use Python lists to store and manage multiple values in a single collection.

#### Requirements
Completed program should:

- Create a list of at least 5 student names or favorite activities
- Display the full list
- Access and print the first and last item in the list
- Add one new item to the list using `append()`
- Print the updated list

### 🛠️ Build a List-Based Program

#### Description
Create a small program that uses a list and functions together to complete a practical task.

#### Requirements
Completed program should:

- Define a function called `add_item(items, item)` that adds an item to a list
- Define a function called `show_items(items)` that prints each item in the list
- Start with a list such as `['milk', 'bread', 'eggs']`
- Add a new item like `'apples'`
- Print the final list in a clean format

### 🛠️ Challenge: Count and Search

#### Description
Extend the program by adding basic list operations such as counting and checking whether an item exists.

#### Requirements
Completed program should:

- Define a function called `count_items(items)` that returns the number of items in the list
- Define a function called `contains_item(items, target)` that returns `True` if the target exists in the list, otherwise `False`
- Demonstrate both functions with sample data
- Print the result of each check clearly

```python
# Example output
shopping_list = ['milk', 'bread', 'eggs']
print(count_items(shopping_list))  # 3
print(contains_item(shopping_list, 'bread'))  # True
```
